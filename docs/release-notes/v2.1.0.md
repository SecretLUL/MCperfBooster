## What's new

### MCperfBooster checks for the Minecraft Launcher
- MCperfBooster sets up Fabric and the mods for the official Minecraft Launcher, and you
  start Minecraft from it. If no launcher is installed, MCperfBooster now says so when it
  starts and offers Mojang's download,
  [aka.ms/minecraftClientWindows](https://aka.ms/minecraftClientWindows): **Yes** opens
  it in your browser, **No** leaves everything as it is.
- It asks on every start until a launcher is found, and never blocks anything. Both
  launchers count: the one from the Microsoft Store or the Xbox app, and the one from
  Mojang's installer, also in a folder you picked during setup. A launcher that is open
  counts too.
- While the launcher is missing, the hints for a missing `.minecraft` folder and the
  Browse warning say to install it first.
